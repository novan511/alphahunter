📋 Legend & Penjelasan Metrik

● Expectancy R: Rata-rata R-multiple per trade (positif = untung bersih)
● Total Return: Return total selama periode walk-forward (modalkan $1000)
● Max Drawdown: Penurunan maksimal dari puncak equity
● Win Rate: Persentase trade yang untung
● Profit Factor: Gross profit / Gross loss ( >1 = untung)
● Sharpe: Return per unit risiko ( >1 = baik)
● RR Ratio: Take Profit : Stop Loss (1:3 = TP 3x SL)
● Prob Threshold: Minimal probabilitas untuk entry (0.65 = 65% confidence)
● SL/TP ATR: Stop Loss dan Take Profit dikalikan ATR (volatilitas)

🔬 Arsitektur Model

Algorithm: XGBoost Gradient Boosted Trees (reg:squarederror)
Target: Forward 3-bar log-return (regresi) — prediksi return 3 candle ke depan
Fitur (14 kolom): RS Z-score, RS Momentum, Asset Return 6-bar, Volume Ratio, ATR%, BTC Regime 20/60-bar, BTC Bull Filter, Momentum 5/20/60-bar, Close/SMA20, RS over RS MA, ATR Regime
Data: ~1000 candle per aset (1d ≈ 3 tahun, 4h ≈ 166 hari)
Walk-Forward: 3 jendela anchored expanding, in-sample → out-of-sample
Position Sizing: Compounded R — 1% risiko per trade, account bertumbuh setelah setiap trade
Exit: Stop Loss (2×ATR), Take Profit (5×ATR = RR 1:2.5), Time Stop (30 bar)
Biaya: Fee 0.1% + Slippage 0.05% per sisi
